# Circuito Qhawa actualizado

Origen: https://wokwi.com/projects/477950143546040321

El único cambio del firmware respecto al proyecto descargado es el broker:
`test.mosquitto.org` → `broker.hivemq.com`. Se conservan el puerto 1883, tópico,
JSON, pines, DHT22, potenciómetro, OLED y LEDs.

En Wokwi reemplaza el contenido de `sketch.ino` por este archivo y guarda tu
proyecto. `diagram.json` y `libraries.txt` son copias de los archivos originales.
El APK actualizado de Qhawa usa el mismo broker que este sketch.

Estos son datos de demostración sobre un broker público. No envíes información
personal ni uses los colores de la simulación como un índice sanitario.
